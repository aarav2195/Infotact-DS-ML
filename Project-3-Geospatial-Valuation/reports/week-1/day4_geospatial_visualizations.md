# Week 1 - Day 4
## Geospatial Visualization using Folium

### Objective

The objective of Day 4 was to visualize the spatial distribution of residential properties using interactive geospatial maps. These visualizations help understand regional pricing patterns and neighborhood distributions before developing spatial machine learning models.

---

## Tasks Completed

- Loaded the processed housing dataset.
- Created an interactive base map using Folium.
- Visualized all property locations on the map.
- Implemented Marker Clustering for improved visualization of dense property regions.
- Generated an interactive Property Price Heatmap.
- Created a Property Price Distribution Map using color-coded price ranges.
- Identified the Top 10 highest-priced properties.
- Generated business insights from geographical property distribution.
