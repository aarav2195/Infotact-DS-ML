# Week 4 – Day 4 Report
## Interactive Business Dashboard

### Objective
Develop a professional business dashboard to visualize the performance of different hotel pricing strategies using Streamlit.

---

## Work Completed

- Developed a Streamlit dashboard for project visualization.
- Designed a professional dashboard layout with a responsive sidebar.
- Added Business Overview KPI cards:
  - Average Revenue
  - Average Rooms Sold
  - Average Occupancy
  - Average Room Price
- Loaded processed evaluation datasets using cached data loading.
- Integrated interactive Plotly visualizations for:
  - Average Revenue Comparison
  - Average Occupancy Comparison
  - Average Rooms Sold Comparison
  - Average Price Comparison
- Displayed strategy comparison table for all evaluated pricing strategies.
- Applied custom CSS styling for improved dashboard appearance and consistency.

---

## Technologies Used

- Python
- Streamlit
- Plotly
- Pandas
- Matplotlib (existing project dependency)

---

## Outcome

A professional interactive dashboard was successfully developed for comparing hotel pricing strategies. The dashboard provides business-focused visualization and serves as the foundation for the final executive analytics dashboard in Week 4 Day 5.
