# Infotact DS ML Internship

This repository contains the projects completed as part of the **Infotact Data Science & Machine Learning Internship**. Each project focuses on solving real-world machine learning problems using industry-standard workflows, feature engineering, model development, evaluation, and deployment.

## Internship Projects

### ✅ Project 1 – Contextual Predictive Maintenance

**Status:** Completed

**Description:**
Developed an end-to-end predictive maintenance system using the AI4I 2020 Industrial IoT dataset. The project includes data preprocessing, signal processing, contextual data fusion, feature engineering, SMOTE-based imbalance handling, LightGBM model training, threshold tuning, noise sensitivity analysis, and deployment through an interactive Streamlit dashboard.

**Key Technologies:**
- Python
- Pandas
- NumPy
- Scikit-learn
- LightGBM
- Imbalanced-learn (SMOTE)
- Streamlit
- Git & GitHub
