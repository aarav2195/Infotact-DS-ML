# Infotact DS & ML Internship

This repository contains the projects completed as part of the **Infotact Data Science & Machine Learning Internship**. Each project focuses on solving real-world machine learning problems using industry-standard workflows including data preprocessing, feature engineering, model development, evaluation, visualization, deployment, and business analytics.

---

# Internship Projects

## ✅ Project 1 – Contextual Predictive Maintenance

**Status:** Completed

### Description

Developed an end-to-end predictive maintenance system using the AI4I 2020 Industrial IoT dataset. The project includes data preprocessing, signal processing, contextual data fusion, feature engineering, SMOTE-based imbalance handling, LightGBM model training, threshold tuning, noise sensitivity analysis, and deployment through an interactive Streamlit dashboard.

### Key Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- LightGBM
- Imbalanced-learn (SMOTE)
- Streamlit
- Git & GitHub

---

## ✅ Project 2 – Dynamic Pricing using Deep Reinforcement Learning

**Status:** Completed

### Description

Designed and implemented an intelligent hotel dynamic pricing system using Reinforcement Learning and Deep Q-Networks (DQN). The project simulates hotel booking seasons, trains pricing agents using Q-Learning and Deep Reinforcement Learning, evaluates pricing strategies through business performance metrics, and presents results using an interactive Streamlit business dashboard.

### Key Technologies

- Python
- Pandas
- NumPy
- PyTorch
- Reinforcement Learning
- Deep Q-Network (DQN)
- Streamlit
- Plotly
- Matplotlib
- OpenAI Gym-style Environment
- Git & GitHub

---

## ⏳ Project 3 – Geospatial Real Estate Valuation
